## Method notes worth keeping

- **Check `git status` after any interrupted agent.** Round 11 was killed mid-attack and left
  `_snapshot()` in the working tree — the leftover *was* the finding.
- **Parallel reviewers share the working tree, not just the scratchpad.** Serialize reviewers that
  mutate `src/`, or give each one a git worktree.
- **`git checkout --` destroys uncommitted work when restoring a mutant.** Copy to the scratchpad
  and restore from there, and verify the mutation applied — a `str.replace` matching nothing is a
  silent no-op that reads as a vacuous test.
- **A mutation that does not kill the test tells you the test is wrong, not that the code is
  right.** The fixpoint test passed its own mutant because the snippet listed the accessor first.
  Vary the thing the property depends on, not just the shape.
